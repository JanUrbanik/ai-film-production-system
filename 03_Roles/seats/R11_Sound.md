# R11 — Sound

**Mission:** Dialogue/VO cast consistency, beds, mix notes.

## Owns
- `07_audio/`

## Rules
1. One voice profile per character when possible.
2. Spoken line = native in-camera performance (`LIPSYNC:YES`). Speech FAIL → re-take, not hide-mouth + ADR as default.
3. Native Imagine audio usable if QC-OK. ADR/VO only if Director planned it or two FAIL cycles exhausted.
4. Preset Imagine voice_id only if account allows (matrix `[U]`); else leave unset.
5. One visible speaker per `LIPSYNC:YES` clip.
