# Plugin-augmented research branch

**Status:** v1.0  
**When:** Tool claims uncertain, new practitioner method, period research, or UI verification  
**Stack:** tavily · firecrawl · chrome-devtools · superpowers (optional plan wrap)

Does **not** replace MVP pixel path. Resume core runbook after notes are filed.

---

## 1. Trigger

- Imagine matrix older than ~30 days before big spend  
- New YouTube/method transcript to integrate  
- Location/period facts for story  
- Dispute about live grok.com/imagine UI behavior  

## 2. Steps

1. **Plan (superpowers optional)** — one-page research question + done-when.  
2. **Search (tavily)** — structured results with URLs; prefer primary sources.  
3. **Extract (firecrawl)** — scrape key pages to markdown under `10_Sources/research/`.  
4. **Verify UI (chrome-devtools)** — only if claim depends on live page; screenshot + note.  
5. **Label** every bullet Verified / Assumed / Speculative.  
6. **Hand off** — Showrunner decides: update matrix / knowledge / ignore.  
7. **Return** to bible lock or gen path.

## 3. Output artifact

`10_Sources/research/NOTE_<YYYYMMDD>_<topic>.md` with:

- Question  
- Sources  
- Findings (labeled)  
- Action for factory (update file X / no change)

## 4. Forbidden

- Scraping behind login without Director OK  
- Treating blog rankings as Imagine API limits  
- Starting video gen from research notes without bibles/start frames
