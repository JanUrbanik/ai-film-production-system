# Bridge: Master Builder Team ↔ Film System

## Principle

| System | Role |
|--------|------|
| `master-builder-team` | Governance OS (ADOPT A, research, truth, tool rating) |
| `ai-film-production-system` | Production factory (bibles, Imagine, QC, edit) |

**Do not merge** film factory into the 16 seats. Bridge by artifacts.

## Handoff forward (Builder → Film)

When a FULL charter concludes “make a film piece”:

1. Builder delivers `FILM_BRIEF_PACKAGE.md`:
   - logline, beats, constraints, budget ceiling
   - likeness/consent
   - success criteria
   - tool rating (Imagine default confirmed)
2. Film system creates `08_Projects/<slug>/` from template.
3. Execution follows MVP or Feature workflow here.
4. Builder seats may **observe/advise** but film roles own generation.

## Handoff back (Film → Builder)

Return:

- Master path + runtime  
- Continuity report  
- Bible versions  
- Cost actuals  
- Open risks / adapter requests  

Builder may run Truth/Deep Analysis on claims before public publish.
