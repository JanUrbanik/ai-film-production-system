# Skill: Emotional distance (push / pull)

| Intent | Move | Notes |
|--------|------|-------|
| Realization / intimacy | Slow push-in / dolly-in | One subject; minimal other action |
| Isolation / aftermath | Slow pull-out | Hold face stability |
| Stay neutral | Locked-off | Default safe |

**Imagine tip:** put move in CAMERA line only; keep ACTION tiny (blink, breath, look).  
**Avoid:** push-in + walk + hand gesture together.
