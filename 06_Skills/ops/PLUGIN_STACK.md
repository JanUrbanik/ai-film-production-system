# Skill: Grok marketplace plugin stack (film factory)

**Authority:** `02_Tools/plugins/GROK_MARKETPLACE_INTEGRATION.md`

## Intent

Use expandable Grok Build plugins for **research, verification, and planning** — never as the camera.

## Enabled defaults

| Plugin | Use |
|--------|-----|
| superpowers | writing/executing plans; verification-before-completion |
| tavily | cited web research |
| firecrawl | scrape/crawl to clean markdown |
| chrome-devtools | live browser proof for UI claims |

## Checklist before claiming “plugin used”

1. Running in Grok Build (or equivalent with MCP)?  
2. `grok plugin list` shows trusted install?  
3. MCP doctor healthy if MCP required?  
4. Output filed under `10_Sources/research/` with labels?  
5. Core Imagine path still required for pixels?

## Anti-patterns

- “Firecrawl can generate the movie”  
- Skipping start-frame gate because research was thorough  
- Installing stripe/neon/etc. for MVP short
