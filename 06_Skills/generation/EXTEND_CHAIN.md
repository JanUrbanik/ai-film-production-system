# Skill: Video extend chain

## When

A PASS take should continue action/camera without a hard cut yet.

## Rules

1. Only extend from **PASS** (or trimmed PASS).  
2. `duration` = **new tail length only** (original + extension = total).  
3. Prompt says what happens **next**, not a full scene rewrite.  
4. QC the junction: identity/morph at seam.  
5. Download combined output; archive parent `request_id`.  

## Pattern

```text
Continue seamlessly from last frame. CAMERA: gentle pan right.
ACTION: he turns and walks two steps into softer light. Calm controlled pace.
```

## Limits

Chaining many extends can accumulate drift (**Assumed**). Prefer coverage cuts for long scenes; use extend for local continuity.
