# Skill: Image-to-video plate lock

## When

Hero framing already approved as still.

## Steps

1. Select LOCKED still (character+env composed or clean plate).  
2. Motion prompt describes **only** what changes (camera + action).  
3. Do not re-describe a different face.  
4. `grok-imagine-video-1.5`, duration 4–10, res 720p (1080p hero).  
5. Multi-take; QC against still + bible.  

## Prompt pattern

```text
Animate this exact frame. CAMERA: slow push-in. ACTION: she blinks and exhales.
Keep identity, wardrobe, and background layout. Subtle ambient city hum.
```
