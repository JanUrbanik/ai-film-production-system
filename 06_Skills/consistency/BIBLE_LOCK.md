# Skill: Bible lock discipline

## Rules

1. DRAFT → generate packs → Director review → **LOCKED**.  
2. LOCKED files are read-only for generators.  
3. Look changes require new look ID + version bump, not silent overwrite.  
4. Shot list pins `bible_version` string.  
5. Mid-project “improve the face” = new version + re-QC prior PASS if used.  

## Version string

`{{char_id}}-v{{n}}-look{{A}}` example: `hero-v2-lookA`
