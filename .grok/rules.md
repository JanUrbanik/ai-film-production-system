# Grok Build Rules — AI Film Production System

## Hard rules

1. **Imagine-first** pixel generation. Plugins do not replace Grok Imagine video/image gen.
2. **Grok-as-camera** law: start-frame first; SUBJECT + CAMERA + HOLD; multi-take (`K-PRAC-GROK-CAMERA-001`).
3. **No identity without refs.** Bible locks before cast motion.
4. **Human Director** final PASS/FAIL, budget, consent, adapter spend.
5. Claim labels: **Verified / Assumed / Speculative**. No fake native 92/100 scores.
6. Prefer installed plugins (**superpowers**, **firecrawl**, **tavily**, **chrome-devtools**) over reinventing research/verify/planning when in Grok Build.
7. MCP auth/quota failures → escalate to Director; never invent tool results.
8. Do not commit secrets (`.env`, `auth.json`, API keys).
9. Relative paths in durable docs; machine abs paths only as operator hints.
10. Optional catalog plugins (exa/figma/…) stay off until Director approves install.

## Task modes

- **MVP pixels:** Deploy checklist A–D → runbooks; plugins optional for research only.
- **Research/tool truth:** tavily + firecrawl + chrome-devtools allowed with citations.
- **Docs/pipeline harden:** superpowers plans + verification-before-completion.
